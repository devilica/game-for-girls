# Dress Up Game

Mobile dress-up game built with **Unity 6** (6000.5.4f1). Two playable modes from the main menu: **Game 1** (girl character) and **Game 2** (pet dress-up).

## Scenes (build order)

| Scene | Purpose |
|--------|---------|
| `SplashScene` | App splash |
| `MenuScene` | Hub: Game 1, Game 2, More Games |
| `MainScene` | Girl dress-up (opening wizard + edit) |
| `PetScene` | Pet dress-up (wizard + edit) |

Play from **MenuScene** or run the full build flow starting at **SplashScene**.

## First-time setup

1. Open the project in Unity **6000.5.4f1** (or compatible Unity 6).
2. **File → Build Settings** — confirm all four gameplay scenes above are enabled (editor tools can refresh this).
3. **Dress Up Game → Generate Pet Items** — builds pet catalog from `Assets/Sprites/Pet/`.
4. **Dress Up Game → Setup Pet Scene** — creates/refreshes `PetScene` UI and wiring (run after scene or hierarchy changes).

For Game 1, use **Dress Up Game → Setup Main Scene** / **Reload Main Scene** when documented in editor menus.

## Game 2 (pet) — content workflow

- **Sprites:** `Assets/Sprites/Pet/` (`Pets`, `Hairbows`, `Collar`, `Glasses`).
- **Items:** `Assets/Resources/Items/Pet/` (ScriptableObjects).
- **Catalog:** `Assets/Resources/PetCatalog.asset`.
- Base pets (`pet_1`, `pet_2`, `pet_3`) plus color variants (yellow, brown, orange, grey) are generated by **Generate Pet Items**; variants share accessory layouts with their base pet.

### Positioning accessories in the Editor

1. Open **PetScene**, select a pet on **Body**, place **Hairbow / Collar / Glasses** in the Scene view.
2. Use **Dress Up Game → Save … Position To … Item** (pet body, hairbow, collar, glasses, or accessory anchors on the pet item).
3. **Dress Up Game → Reset Pet Layer Positions** to reset transforms to base anchors.

## Game 1 (girl) — layers

New character layers must follow the checklist in `.cursor/rules/character-layers.mdc` (scene hierarchy under `Girl`, `CharacterCustomizer`, save tools, **Reload Main Scene**).

## Useful editor menu (`Dress Up Game`)

| Item | Use |
|------|-----|
| Setup Main Menu Scene | Menu hub |
| Setup Main Scene / Reload Main Scene | Game 1 scene |
| Setup Pet Scene / Reload Pet Scene | Game 2 scene |
| Generate Pet Items | Pet catalog + items |
| Link Sprites From Folder | Wire sprites to items |
| Save layer position tools | Persist layout to ScriptableObjects |
| Build Release AAB (Play Store) | Android release build |
| Configure AdMob App ID | Ads setup |

## Runtime features (overview)

- **Ads:** Rewarded gates on selected item cards; bottom banner; tea break + interstitial between wizard steps (Game 1 and Game 2 where configured).
- **Save:** `PlayerPrefs` for character and pet selections / wizard completion.
- **UI:** Portrait layout, safe area, home button back to menu from gameplay scenes.

## Android release

Use **Dress Up Game → Fix Play Store Build Settings** and **Build Release AAB (Play Store)**. Keep signing keys and passwords out of git; use local keystore configuration only on your machine.
